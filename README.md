# P30: Koopman/EDMD Forecasting of MRSA Spread on a Hospital Contact Network

CMDS course project (M.Tech Data Science, Amrita Vishwa Vidyapeetham), topic P30.

Lifts ward-level MRSA colonization observables from a dynamic patient-contact
graph into a Koopman-operator framework via EDMD, forecasts outbreak
trajectories, and evaluates Koopman-eigenmode-based superspreader-ward
targeting against simple network centrality.

Author: Kiran Gautham. Revised after an internal review on November 14, 2026
(see REPORT.md, "Revision note").

## Data

Source: I-Bird study, a 200-bed long-term/rehabilitation hospital in
Berck-sur-Mer, France, 2009 — see [Citation](#citation).

The raw CSVs are **not** included in this repository (`data/` is gitignored;
dataset license unverified). To reproduce, place these three files in
`data/raw/`:

- `admission.csv` — person -> ward/group
- `mat.day.csv` — daily contact edges
- `microbio.csv` — MRSA swab results

## Reproducing the full pipeline

Run everything in one command:

```bash
python run_all.py
```

Each phase reads the previous phases' saved outputs from `data/processed/`
and `results/`, so if running manually, the order below must be preserved:

| Phase | Command | Produces |
|---|---|---|
| P1 | `python -m src.audit` | Data audit |
| P2 | `python -m src.build_network` | Contact network + ward matrix W |
| P3 | `python -m src.build_states` | Real weekly prevalence |
| P4 | `python -m src.build_simulation` | SIS simulation + calibration |
| P5 | `python -m src.build_observables` | EDMD dictionaries + train/val/test split |
| P6 | `python -m src.build_edmd` | EDMD fit |
| P7 | `python -m src.build_eigen` | Eigenmode analysis + Koopman influence score |

## Key results (see REPORT.md for full detail)

**P4 — calibration.** The data bound the MRSA decolonization rate only
from above (gamma up to about 2e-3/day is within 5% of the best loss); the
calibrated simulator is a closed population with almost no decolonization.

**P6 — EDMD fit.** Proved analytically and confirmed empirically that the
contact-weighted dictionary D3 adds no function space beyond the plain
polynomial dictionary D2: D3's fitted operator has rank 19 of 25, exactly
matching the theoretical ceiling. All three operators have spectral radius
slightly above 1 (1.014-1.022).

**P8 — real-data forecasting.** No EDMD variant beats persistence on the
real holdout weeks. One week ahead they are indistinguishable at every
calibration point; at 3-4 weeks the small gap (at most 0.0064 RMSE, about a
tenth of the sampling error) changes sign along the calibration ridge.

**P9 — superspreader validation.** Degree centrality matches the 50%-cut
ground truth best (Spearman rho = 0.94, exact p = 0.017), but that ground
truth largely rewards contact volume by construction. Under an equal
contact-hours ground truth no candidate, Koopman or centrality, ranks the
wards reliably.

**P10 — intervention simulation.** Targeting the highest-contact wards beats
random and whole-hospital allocation at every budget (paired 95% CIs exclude
zero); some Koopman choices do worse than random. The best strategy prevents
under 5% of colonized person-days.

**P11 — robustness.** The 50%-cut ward ranking is stable across seed,
replicate count, calibration point, network window and population; the
Koopman eigenmode ward shares are not (E8). E9 reruns P4-P10 at all five
near-optimal calibration points: degree rho = 0.94 and "degree targeting
beats random/whole-hospital" (20 of 20) hold everywhere, while Koopman
scores swing between -0.77 and 0.83 and beat degree targeting in only 1 of
60 comparisons.

## Limitations

- About 16 real weekly snapshots only; the decolonization rate is not identified.
- Closed simulated population (no admission/discharge dates), so it cannot reproduce declining prevalence.
- Time-invariant Koopman operator fit against a time-varying contact network.
- Only 6 groups, so rank statistics are weak.
- Contact network only, no transfer records.
- Ground truths and Koopman scores come from the same calibrated simulator.
- Single hospital, single 4-month observation window.
